# 量产测试逻辑

### 启动方式

- PA9或PA10接地后给设备上电

### 测试流程

1. 上电先进入低功耗模式
  - 触发限位开关信号后唤醒开始运行功能
  - (检验低功耗和限位功能)
2. 唤醒后,WiFi 模块初始化
  - 此时WIFI未连接 指示灯LED1慢闪
  - WIFI 将在启动初始化 5 秒后（初始化完成时间）自动连接无线网名称 12345678 密码 12345678
  - 每秒尝试连接判断WIFI连接情况(最多尝试连接15s);
    - 连接中，LED1快闪
    - 连接成功后, LED1常亮;
    - 连接失败, LED1熄灭
3. 设置一个固定电压3.7V,靠芯片自身判断电压检测的准确性
  - LED2红灯常亮
  - 检验电压采集电路;异常(小于3.65或大于3.75)LED2熄灭
4. 电机交替正反转,接入实际电机负载
  - 正转5s 停止 0.5s 反转5s  停止0.5s  循环
  - 芯片判断电流是否在范围内20-150mA()
  - 检验电流检测电路，正常LED3红绿灯交替闪烁,异常LED3熄灭
5. 按键K1,K2按下伴随蜂鸣器响
  - 检验按键和蜂鸣器

- 正常插适配器充电观察充电电流(检验充电电路)
